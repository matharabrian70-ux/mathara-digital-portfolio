# Menu Engineering Workbench — prototype
Browser-only calculator for menu item contribution and relative menu performance.

Calculations:
- Contribution per unit = selling price minus ingredient cost and packaging cost.
- Food cost percentage = ingredient cost / selling price.
- Total revenue and contribution = per-unit values multiplied by the supplied unit sales.

The Star / Plowhorse / Puzzle / Dog labels compare each item to the average unit sales and average contribution in the dataset entered. They are internal relative categories, not universal industry targets. This is decision-support software, not an accounting, tax or POS system. It has no backend and stores no data beyond the browser session unless the operator exports it.
